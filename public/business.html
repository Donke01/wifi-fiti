Set up a router

Tell us the hardware and network shape. WiFi Fiti creates a unique, copy-once RouterOS kit for this location.

For a new or reset router, the kit creates the customer Wi-Fi, Hotspot and secure cloud connection. For an existing router, it preserves your network and only installs WiFi Fiti pairing.

1 · Describe itRouter, network and Hotspot details.
2 · Generate onceA unique router token stays in this browser session.
3 · Connect routerCopy the installer into a new WinBox terminal.

New router network

These fields become the customer Wi-Fi. Connect by MAC WinBox or Ethernet while importing; do not run this kit on a router that already serves people.

The router password is never requested or stored.

Remote onboarding

After one local pairing, securely complete a verified router setup. Customer traffic and payments never use this path.

Connect the router to the internet and install its WiFi Fiti pairing kit once. After it checks in, approve a private managed-service refresh from its location card. WiFi Fiti never exposes WinBox, API, or SSH to the public internet.

1 · Pair locally oncePaste or import the router-specific kit from the setup wizard.
2 · Wait for secure check-inThe router verifies its identity and private connection.
3 · Apply WiFi Fiti serviceWiFi Fiti rechecks the confirmed map, then refreshes only its owned service controls.
